# Machine Learning — Transformers

Transformers process sequences using attention rather than recurrent computation.

## Self-attention

Self-attention allows every token to evaluate the relevance of other tokens in the same sequence.

The mechanism uses three learned representations:

- query
- key
- value

Attention scores determine how strongly information from different positions should contribute to the output.

## Multi-head attention

Multiple attention heads allow the model to learn different relationships simultaneously.

Transformers are used in language models, vision systems, speech processing, and multimodal architectures.
