NoteIndex

NoteIndex is a local desktop application for managing, importing and searching study notes.

Overview

The application allows users to import text-based documents, store them locally, and search through their contents using a full-text search engine. It provides both a graphical user interface and a command-line interface.

Requirements and Technology

NoteIndex targets Java 25 and is built with Maven. Its desktop interface uses JavaFX, and persistent document storage uses SQLite through JDBC.

Architecture

The project is organized into several independent modules:

  • noteindex-core - shared domain models and exceptions.
  • noteindex-importer - document importing system and format support.
  • noteindex-persistence - SQLite-based document storage.
  • noteindex-search - indexing, querying, and ranking engine.
  • noteindex-application - application workflows and services.
  • noteindex-cli - command-line interface.
  • noteindex-gui - JavaFX desktop interface.

Main Features

  • Importing Markdown and plain text documents.
  • Local SQLite document storage.
  • Full-text and prefix search with ranking.
  • Exact quoted phrase searching and highlighted results.
  • Document management through GUI and CLI.

Persistence

SQLite is the authoritative persistent storage for NoteIndex. The in-memory search index is derived state, is synchronized with stored documents, and can be rebuilt from the database.

User Interfaces

The application provides:

  • A JavaFX graphical interface for everyday use.
  • A command-line interface for terminal-based workflows.
